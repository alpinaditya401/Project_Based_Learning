Terdaftar, menunggu koneksi

  1. Nyalakan unit dan ikuti panduan pemasangan paket.
  2. Masuk ke mode pengaturan WiFi pada perangkat.
  3. Sambungkan HP ke jaringan pengaturan perangkat.
  4. Isi WiFi lokasi melalui halaman perangkat, lalu kembali ke AquaSmart.

Pengaturan WiFi masih menunggu integrasi firmware. Website ini belum mengirim atau menyimpan password WiFi ke unit.

Belum pernah heartbeat = waiting, bukan offline. Tombol uji fisik tidak aktif sebelum kontrak firmware tersedia dan gate hardware dibuka. Formula koneksi.
